# Tech Club Management System

A team project developed using **Odoo ERP** to simplify the management of a technical club through a centralized administrative dashboard.

## Overview

The system helps manage club operations in one place, including:

- Member Management
- Event Management
- Attendance Tracking
- Task Management

## Features

- Manage club members and their technical tracks.
- Create and organize events and workshops.
- Record attendance for each event.
- Assign tasks and monitor their progress.
- Centralized dashboard for club administration.

## Technologies Used

- Odoo 19
- Python
- PostgreSQL
- Git & GitHub
